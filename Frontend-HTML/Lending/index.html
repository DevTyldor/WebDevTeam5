Regels

De belangrijkste bedrijfsregels van het uitleensysteem.
1
Alleen de eigenaar beslist Een aanvraag kan alleen door de eigenaar van de betreffende doos worden goedgekeurd of afgewezen.
2
Andere aanvragen vervallen Zodra een aanvraag voor een doos wordt goedgekeurd, worden alle andere openstaande aanvragen voor die zelfde doos automatisch afgewezen.
3
Een uitgeleende doos kan niet opnieuw worden uitgeleend Een doos kan pas opnieuw worden aangevraagd nadat de huidige lening is beëindigd en de terugkomst is geregistreerd.
4
Terugkomst wordt geregistreerd De eigenaar of de commissie registreert wanneer de doos terugkomt.
5
Eén verlenging Een lening kan maximaal één keer worden verlengd en alleen zolang de lening nog niet te laat is.
6
Maximale uitleenperiode De nieuwe retourdatum moet binnen de maximale uitleenperiode blijven, gerekend vanaf de startdatum van de lening.

Datamodel

De gegevens die voor ieder onderdeel moeten worden bijgehouden.

📦 Box

Een fysieke speldoos die door een lid beschikbaar wordt gesteld.

  • owner Member
  • game Game
  • condition Text

🙋 Request

Een verzoek van een lid om een bepaalde doos te lenen.

  • box Box
  • member Member
  • status Pending / Approved / Rejected

🤝 Loan

Een actieve of afgeronde uitleenperiode van een doos.

  • box Box
  • borrower Member
  • startDate Date
  • returnDate Date
  • extended Boolean
  • returnedDate Date / null
